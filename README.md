# Dot Tycoon

写真から**特徴**（髪・肌・服・背景の色、髪型、表情、メガネ）を読み取り、
16×16 のドット絵キャラに**描き直す**Webアプリです。

写真を縮小・減色するのではなく、「特徴を抽出 → 16×16 のキャラに当てはめる」方式です
（手元の参考ドット絵（16×16）と同じ配置・頭身で描きます）。
処理はすべてブラウザ内で完結し、画像は外部に送信されません。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173
```

- 画像をドロップ / 選択 / 貼り付け（Ctrl/⌘+V）
- 読み取った特徴はフォームで**直接直せます**（色・髪の長さ・前髪・目・口・メガネ・背景）
- 保存形式: PNG / WebP / GIF / SVG / JPEG、倍率 1×〜64×（最近傍拡大。PNG・WebP・GIF・SVG は透過に対応）
- 「解析結果を重ねる」で、検出した顔の範囲と 髪/肌/服 の領域を確認できます

`npm run dev` / `npm run build` は、初回に MediaPipe の WASM とモデル（約 20MB）を
`public/` に用意します（モデルは MediaPipe 公式の配布元から取得）。実行時に外部 CDN は使いません。

## GitHub Pages へのデプロイ

`.github/workflows/deploy.yml` を同梱しています。リポジトリの
Settings → Pages → Source を **GitHub Actions** にして `main` に push すると、
テスト → ビルド → デプロイされます。`vite.config.ts` は `base: './'`（相対パス）なので、
リポジトリ名に関わらずそのまま動きます。

## 仕組み

```
画像 ─ 顔の検出(Face Landmarker) ─ 傾き補正
     └ 領域分割(髪/顔肌/体肌/服/背景/その他) ─┐
                                              ├─ 特徴(Features) ─ 16×16 描画 ─ 保存
     表情(blendshapes) ───────────────────────┘
```

| ファイル | 役割 |
|---|---|
| `src/detect.ts` | MediaPipe（顔ランドマーク + セグメンテーション）。顔の傾き補正 |
| `src/features.ts` | 検出結果 → 特徴。純関数（MediaPipe に依存しないのでテスト可能） |
| `src/render.ts` | 特徴 → 16×16 のドット絵。純関数 |
| `src/export.ts` | PNG / WebP / GIF / SVG / JPEG への書き出し |
| `src/main.ts` | UI |

読み取る特徴: 髪色・肌色・目の色(虹彩)・唇の色・服の色・背景色 /
髪の長さ（坊主〜長い）・前髪（なし/分け/流し/ぱっつん）・ボリューム /
目（ひらく/おおきい/にっこり/とじる）・口（ふつう/ほほえみ/歯/あけ口）/ メガネ・サングラス

## 既知の限界

- **透明レンズの普通のメガネは、見逃しが多い**です。サングラスは、セグメンテーションの
  「その他」クラスで確実に検出できますが、普通のメガネは目元の画像を MobileNetV3 で埋め込み、
  線形分類器で判定しています（`src/glasses-model.ts`）。交差検証（473枚）では AUC 0.89 で、
  メガネなしの誤検出を5%に抑えると、メガネを見つけられるのは約4割です。
  見逃したときはフォームで「メガネ」を選んでください。誤検出を避けるため、しきい値は厳しめです。
  学習データは Wikimedia Commons のカテゴリ名で分けただけなので、ラベルに誤りが混ざっています
  （色の線を探す方法・CLIP のゼロショットも試しましたが、精度が出ませんでした）。
- **ひげ**は検出しません（セグメンテーション上は顔の肌と区別されず、色だけでも判別できませんでした）。
- 髪の長さ・前髪・ボリュームは、髪の領域の形から推定する簡易ルールです。
  帽子・結んだ髪・強い逆光では外れることがあります。
- **イラストにも対応していますが、実写より精度は低い**です（試験的）。
  - 顔検出モデル（MediaPipe）は実写で学習されているため、イラストでは全体を探して見つからないとき、
    画像を拡大しながらずらして顔を探します（数秒かかります）。
  - 人物セグメンテーションもイラストにはほぼ効かないので、イラストと判断したときは、
    顔の肌の色と背景の色を手がかりに、髪・肌・服を色の近さで分けて代わりに使います（`src/illustration.ts`）。
  - 苦手なもの: 白い背景に白い髪、フードや帽子、顔が極端にデフォルメされた絵（目が大きすぎるなど）。
    検出できたときも、髪型や色は必ずフォームで確認・修正してください。
  - 検証した絵は 7 枚だけです（Wikimedia Commons のイラストと、コスプレ写真が混ざったセット）。
- 人物のみ対応です。動物は未対応（今後の課題）。
- 顔が小さい（全身写真など）と、髪・服の色の精度が落ちます。
- 検証した画像は 11 枚程度で、しきい値（`src/features.ts` 内）はその範囲での調整です。

## 開発

```bash
npm test          # 単体テスト（合成の顔で特徴抽出も検証）
npm run typecheck
npm run build
```

手元に `reference/`（元になった16×16のドット絵SVG。公開リポジトリには含めていません）があるときは、
`tests/render.test.ts` が同じ形を再現できることも確かめます。なければその部分は飛ばされます。

メガネ分類器の学習用ツール（`train.html`, `src/train/`, `tools/collect_dataset.py`）は開発専用で、
本番ビルドには含まれません。学習には `npm run setup:train` で追加モデルを取得します。
